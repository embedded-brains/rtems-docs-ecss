# Fonts of the documentation index page

The documentation index page uses the fonts of the Sphinx documents it links
to.  The files come from the `sphinx_rtd_theme` package.

| File                        | Font        | Licence      |
| --------------------------- | ----------- | ------------ |
| `lato-normal.woff2`         | Lato        | `OFL-1.1`    |
| `lato-bold.woff2`           | Lato        | `OFL-1.1`    |
| `Roboto-Slab-Regular.woff2` | Roboto Slab | `Apache-2.0` |
| `Roboto-Slab-Bold.woff2`    | Roboto Slab | `Apache-2.0` |

The licence texts are in `LICENSES/`.
